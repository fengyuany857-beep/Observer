This isolated visual prototype references or adapts ideas from the following open-source projects. It does not add them as runtime package dependencies.

Repository: https://github.com/idleCyrex/topolines

Used as a reference for:
- deterministic procedural topographic fields
- two-octave fBM composition
- domain-warped contour aesthetics
